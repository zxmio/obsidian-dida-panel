# 滴答面板设计规范

2026-10-28 · 适用于 `plugins/dida-panel` 的全部界面：侧栏面板、看板、弹出面板、弹窗、AI 对话框、笔记内嵌任务块。

## 为什么要这份规范

到今天为止，界面是一轮一轮加出来的，每轮各自定了一套数值。盘点 `styles.css`（3350 行）的结果：

| 项目 | 现状 | 规范后 |
|---|---|---|
| 圆角 | 12 种（4 / 5 / 6 / 7 / 8 / 10 / 11 / 12 / 14 / 20 / 999 / 50%） | 5 档 |
| 字号 | 16 种（11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 15 / 16 / 18 / 20 / 22 …） | 6 档 |
| 写死的颜色 | 约 40 个 rgb / 十六进制值散落各处 | 全部走语义变量 |
| 颜色变量块 | 3 处重叠定义（面板骨架、Notion 任务行、对话框各一套） | 1 处 |
| 菜单 | 原生菜单和自绘面板混用，弹窗里还剩 2 处原生菜单 | 全部自绘面板 |

结果就是你说的「改了这个漏了那个」。规范的目标是：**所有数值只在一个地方定义，组件只引用变量；再加一道自动检查，写死的值进不了仓库。**

## 一、设计原则

1. **视觉以我们自己的设计稿为准，交互借鉴滴答。** 现行设计稿是 Design 画布「滴答面板 · 精修版」（纸感极简）：今天看板、项目总览、项目看板、组件与状态四个画板，其中「组件与状态」是逐项对照的总表。一套中性灰 + 一个品牌红，大块灰底一律换成白底 + 细环，已完成退到后面。滴答只借交互：分组「···」菜单、速记、右键。颜色和字体跟随 Obsidian 主题变量，深浅模式自动适配。
2. **品牌红是唯一强调色。** 只用在：主按钮、选中态、焦点环、「派给 AI」入口、默认标记。其余状态色（红橙蓝绿）只表达语义：优先级、过期、完成。
3. **平时安静，悬停才露操作。** 行和卡片默认只显示内容；操作按钮、清除、删除在悬停或聚焦时出现，位置固定在右侧，不挤动文字。
4. **一种操作只有一种样子。** 同一类控件（菜单、胶囊、输入框、按钮）全站一个组件、一套尺寸，右键和「···」打开同一个面板。
5. **不可逆先确认，做不到要说清。** 删除、归档先弹确认框；滴答接口不支持的（删除分组、删除项目）明说原因，并给出替代路径。

## 二、设计变量（Token）

全部定义在 `styles.css` 顶部唯一的变量块里，作用于 `.dida-host, .dida-panel, .dida-modal, .dida-block, .dida-pop, .dida-dock` 六个根。深色模式只覆写颜色变量，尺寸变量不变。

### 2.1 颜色

| 变量 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--dida-canvas` | `#fbfbfa` | `var(--background-primary)` | 面板页面底 |
| `--dida-fill` / `--dida-fill-strong` | `#f3f3f1` / `#ebebe8` | 半透明白 | 悬停底、分段轨道、范围胶囊；只用于这几处，不做大块底 |
| `--dida-line` / `--dida-line-strong` | `#ececee` / `#e2e2e5` | 主题边框 / 半透明白 | 细线 / 输入框与筛选胶囊的细环 |
| `--dida-text-2` / `--dida-text-3` | `#5c5c63` / `#75757b` | 主题次要 / 辅助 | 次要 / 辅助小字（白底对比度 4.6:1） |
| `--dida-surface` | `var(--background-primary)` | 同左 | 弹窗、输入框聚焦底 |
| `--dida-surface-raised` | `var(--background-primary)` | `var(--background-secondary)` | 卡片、悬停浮起的行、弹出面板 |
| `--dida-surface-sunken` | `rgba(55,53,47,.035)` | `rgba(255,255,255,.03)` | 次级区块底 |
| `--dida-check-line` / `--dida-check-medium` / `--dida-check-done` | `#d4d4d8` / `#8e8e94` / `#e4e4e7` | 半透明白 | 勾选框：默认圈 / 中优先级圈 / 已完成实心 |
| `--dida-fill` | `rgba(55,53,47,.06)` | `rgba(255,255,255,.055)` | 输入框底、悬停底、次级胶囊底 |
| `--dida-fill-strong` | `rgba(55,53,47,.1)` | `rgba(255,255,255,.1)` | 按下、悬停中的胶囊 |
| `--dida-line` | `var(--background-modifier-border)` | 同左 | 分隔线、描边 |
| `--dida-text` / `-2` / `-3` | `--text-normal` / `--text-muted` / `--text-faint` | 同左 | 正文 / 次要 / 辅助 |
| `--dida-accent` `-strong` `-soft` `-line` `-rgb` | `#c04638` 系 | `#e8806f` 系 | 品牌强调 |
| `--dida-red` `--dida-orange` `--dida-blue` `--dida-green` | `212,76,71` / `217,115,13` / `51,126,169` / `68,131,97` | 提亮一档 | 语义色（图标、文字） |
| `--dida-red-soft` 等 | Notion 选项色浅底 | 半透明深底 | 语义色块底色 |

语义映射固定下来，不再各处自己挑：

| 含义 | 颜色 |
|---|---|
| 高优先级（勾选框红圈）、过期日期、过期泳道名 | 品牌红：圈用 `--dida-accent`，文字用 `--dida-accent-strong` 500 |
| 中优先级（勾选框深灰圈） | `--dida-check-medium` |
| 今天的日期 | `--dida-text` 500（不另起颜色） |
| 正文笔记链接 | `--dida-accent` |
| 已完成、子任务全部完成 | 绿 |
| 删除、错误 | 红 |
| 低 / 无优先级、未设置 | `--dida-check-line` / `--dida-text-3` |

设计稿是「中性灰 + 一个品牌红」，橙蓝绿只在体检分类、数字卡图标这类需要区分种类的地方出现，任务和分组上不用。

### 2.2 字号

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--dida-fs-xs` | 11px | 计数、角标、序号、徽标 |
| `--dida-fs-sm` | 12px | 属性行（日期、标签、项目名）、胶囊、次要说明 |
| `--dida-fs-md` | 13px | 正文、菜单项、输入框、按钮 |
| `--dida-fs-lg` | 14px | 任务标题、分组列名 |
| `--dida-fs-xl` | 16px | 视图标题（项目名、AI 队列） |
| `--dida-fs-2xl` | 20px | 弹窗标题、数字卡大数字 |

字重只用三档：400 正文、500 标签和次标题、600 标题。

### 2.3 间距、圆角、尺寸

- **间距**：4px 网格，只用 `2 / 4 / 6 / 8 / 12 / 16 / 20 / 24`。行内元素间距 6，组件内边距 8–12，区块间距 16–20。
- **圆角** 5 档：

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--dida-r-xs` | 6px | 行内小按钮（笔记链接、卡片悬停操作）、徽标 |
| `--dida-r-sm` | 8px | 图标按钮、菜单项 |
| `--dida-r-md` | 10px | 列表行、输入框、按钮、数字卡 |
| `--dida-r-lg` | 12px | 卡片、弹出面板、弹窗、拖拽落点 |
| `--dida-r-full` | 999px | 勾选框、标签、分段控件、页签、跳转胶囊 |

- **控件高度** 4 档：`--dida-h-xs` 24（图标按钮、小胶囊）· `--dida-h-sm` 28（胶囊、行内按钮）· `--dida-h-md` 32（菜单行、输入框、普通按钮）· `--dida-h-lg` 36（弹窗主按钮、快速添加框）。按钮和输入框的高度一律用这 4 个变量。
- **图标** 4 档：12（属性行内）· 14（按钮、菜单）· 16（工具栏）· 18（常用动作大按钮）。线宽跟随 Obsidian。

### 2.4 层级（阴影）

| 变量 | 用在哪 |
|---|---|
| `--dida-e1` | 卡片静止：一圈 5% 细环 + 贴边细影 + 大范围淡影 |
| `--dida-e2` | 卡片悬停、展开（各加深一档） |
| `--dida-e-row` | 列表行、项目行悬停，数字条：只有细环 + 贴边细影 |
| `--dida-e-float` | 卡片右上角浮出的操作组 |
| `--dida-e-composer` | AI 输入框 |
| `--dida-e-drag` | 被拖动的卡片 |
| `--dida-e-tab` | 页签、分段控件选中项的那一点浮起 |
| `--dida-e3` | 弹出面板（Notion 菜单的三层阴影） |
| `--dida-focus` | 焦点环：`0 0 0 3px rgba(accent,.12)` + 强调色描边 |

弹窗沿用 Obsidian 自己的阴影，不另外定义。

### 2.5 动效

悬停、按下：`120ms ease`。弹出面板出现：`120ms ease-out`，上移 3px 淡入。折叠箭头旋转：`150ms`。不做位移超过 4px 的动画，不做弹跳。

## 三、组件规范

每个组件只有一个类名入口，列出的变体之外不新增。

### 3.1 按钮

**先清掉 Obsidian 的默认按钮样式。** Obsidian 用 `button:not(.clickable-icon)`、`button:hover` 给所有按钮铺白底和投影，权重高于只写类名的规则，这就是页签、图标按钮曾经各顶一个白框的原因。现在变量块之后有一条基础重置，把插件里的按钮清成透明；**所有按钮组件的选择器一律写成 `button.类名`**（权重高于重置，靠先后顺序胜出）。新增按钮组件必须遵守这条。

| 变体 | 样子 | 用在哪 |
|---|---|---|
| 主按钮 | 强调色实底白字，高 36，圆角 sm | 弹窗的「创建 / 保存」 |
| 次按钮 | 白底细描边，高 32 | 「取消」、展开卡片里的操作 |
| 幽灵按钮 | 透明底，悬停铺 `--dida-fill` | 「新建分组」「新建项目」虚线行、工具栏 |
| 危险幽灵 | 灰字，悬停变红 | 「归档项目」「删除」 |
| 图标按钮 | 24 / 28 正方形，图标 14 / 16 | 工具栏、行内操作 |

### 3.2 输入框

一种「填充式」：`--dida-fill` 底、无描边、圆角 md；聚焦时变白底 + `--dida-focus`。快速添加、搜索、新建分组、添加子任务、面板搜索框全部用它，只在高度上取 sm / md / lg。

### 3.3 胶囊与徽标

| 组件 | 规则 |
|---|---|
| 属性胶囊（快速添加下的日期、优先级…） | 高 26，未设置灰字透明底，设置后 `--dida-fill` 底；优先级用语义色浅底 |
| 标签 | 高 18，圆角 full，字号 sm，滴答标签色 16% 浅底 + 45% 深字；没设颜色的灰底 |
| 优先级 | 不单独显示，看勾选框的圈 |
| 计数 | 纯文字 `--dida-text-3`，字号 xs，跟在名称后空 6px |
| 徽标（默认、未安装、过期数） | 高 18，圆角 xs，字号 xs |

### 3.4 勾选框（照设计稿）

**圆形 16px**，白底，1.5px 圈。默认浅灰圈；**高优先级品牌红圈，中优先级深灰圈**，低和无优先级都是默认圈。勾上时实心填充圈色、白色对勾；**已完成**是浅灰实心（`--dida-check-done`）+ 灰色对勾，标题转辅助色，**不画删除线**，看板里的已完成卡片去掉底色和投影。

### 3.5 任务行与任务卡片

- **列表行**：内边距 8 / 10，圆角 md，平时无底；**悬停或展开时浮成一张白卡**（`--dida-surface-raised` + `--dida-e1`）。项目总览的项目行、搜索结果用同一种悬停。
- **卡片**（看板）：白底，圆角 lg，内边距 10 / 12，`--dida-e1`，悬停 `--dida-e2`；拖动中原卡片半透明。
- 勾选框和正文间距 10。标题 `fs-lg` 400，行高 1.45；属性行 `fs-sm` 浅灰，间距 8，元素顺序固定：**日期 → 子任务进度 → 项目 → 标签 → 关联笔记**。过期日期品牌深红 500。
- 子任务缩进 28px，左侧不画竖线。
- 悬停操作组固定在右上角：派给 AI、编辑、更多；右键等同「更多」。

### 3.6 分组标题与泳道（照设计稿）

- **分组标题**（列表视图）：折叠箭头 12px + 名称（fs-md 500，`--dida-text-2`）+ 计数（浅灰 400）；分组之间空 22px；悬停在右侧露出「···」。
- **泳道**（看板）：**没有底色**，宽 264，卡片间距 8，泳道间距 12（主窗格 16）。标题一行：名称（fs-md 500 次要色）+ 计数 + 右侧「+」（常显，点了光标进底部添加行）+「···」（悬停才出现）。
- **添加行在泳道底部**：一行淡字「+ 添加到 XX」，点进去就是输入框，聚焦时浮成一张白卡；回车即建、支持速记、光标留着继续加。
- **长泳道折叠**：默认显示 8 张，其余收进「还有 N 条 · 展开」，展开后可「收起」。
- **拖拽落点**：卡片拖进泳道时，顶部空出一个淡红虚线框（`--dida-accent-line` 虚线 + `--dida-accent-soft` 底，圆角 lg）。
- **分组「···」菜单**：重命名、在左侧 / 右侧添加分组、左移 / 右移、删除。重命名、添加、移动走 `update_column` / `create_column`；删除说明原因并打开网页版。

### 3.7 弹出面板（所有菜单）

一个组件 `QuickPopover`，全站不再使用 Obsidian 原生菜单。

- 宽度三档：窄 200（优先级）· 标准 240（通用操作）· 宽 288（任务操作、派送、日期）。
- 可选头部：emoji + 名称 + 一行 `fs-sm` 小字。
- 行高 32，图标 14，右侧依次是徽标、悬停次要操作、快捷键序号、对勾。
- 分组之间用 1px `--dida-line` 分隔；危险项放最后一组，红字。
- 键盘：上下键移动、回车选择、数字键直选（有序号时）、Esc 关闭并把焦点还给触发处；同一时间只开一个。

### 3.8 弹窗

任务、项目、体检、确认四种弹窗共用：标题区（小字类别 + 20px 标题）→ 属性区（胶囊行，左侧 40px 标签）→ 内容区 → 底栏（左危险幽灵按钮，右「取消 + 主按钮」）。弹窗里剩下的 2 处原生菜单（日期、优先级）换成弹出面板。

### 3.9 其他

- **数字卡**：圆角 md，`--dida-e1`，标签 fs-sm + 图标，数字 fs-2xl 600。
- **空状态**：居中一句 fs-sm `--dida-text-3`，不放插画；能操作时给一个幽灵按钮。
- **加载**：文字「加载中…」fs-sm 灰色；按钮内用旋转图标，不用整页遮罩。
- **通知（Notice）文案**：动作完成用「已 + 动词」（「已归档『X』」），失败用「X 失败：原因」，接口不支持时说清原因和替代做法。

## 四、交互规范

| 场景 | 规则 |
|---|---|
| 打开菜单 | 「···」按钮和右键打开同一个面板，面板贴着按钮或鼠标位置 |
| 选择后 | 单选立即生效并关闭；多选（标签）保持打开 |
| 删除 / 归档 | 必须确认；确认框说明影响范围和能否找回 |
| 接口不支持 | 不隐藏入口，点了说明原因并给替代路径 |
| 新建后 | 新对象立刻出现在本地（不等接口回读），几秒后再对一次账 |
| 键盘 | 所有弹出面板支持上下、回车、Esc；输入框回车提交、Esc 取消 |
| 焦点 | 关闭面板后焦点回到触发处；连续添加（子任务、快速添加）时保持在输入框 |

## 五、升级计划

分四步，每步做完都能单独用、单独验证。

**第一步：变量层。** 把现有 3 处颜色变量块合并成第二节的唯一变量块；补上字号、圆角、高度、阴影变量。这一步不改任何组件外观。

**第二步：逐组件替换。** 按第三节的顺序，把每个组件里写死的数值换成变量、并到规定的变体上。涉及：面板骨架、快速添加、属性胶囊、弹出面板（日历、派送、任务操作、通用操作）、项目总览、列表行、勾选框、看板、弹窗、任务体检、AI 对话框、内嵌任务块。

**第三步：对齐滴答的交互。**
- 勾选框按优先级着色。
- 泳道顶部「+ 添加任务」条。
- 分组「···」菜单：重命名、左右添加、左右移动、删除。
- 弹窗里剩下的两处原生菜单换成弹出面板。

**第四步：防回退检查。** 新增 `tests/styles.test.mjs`：读取 `styles.css`，变量块以外出现十六进制颜色、`rgb()`、不在档位里的圆角或字号就失败，并列出行号。以后谁再写死一个值，`npm test` 直接报出来。

每步都用浏览器样稿过一遍浅色和深色，再装进 vault。

### 不在这次范围

- 滴答那种点开卡片浮出的「任务详情浮层」（截图二）。现在展开卡片和编辑弹窗已经覆盖编辑功能，浮层是一块新界面，建议规范落地后单独做。
- 强调色换成滴答蓝。规范里强调色是一个变量，想换只改一处。

## 六、落地记录（2026-10-28）

### 第三轮：精修版（纸感极简）

- 设计稿换成「滴答面板 · 精修版」，代码按它升级：页签改成文字 + 品牌红下划线；图标按钮无底；快速添加与 AI 输入框改成白底细环；三张数字卡合成一条分三格的细卡（去掉图标）；项目行 36 高、悬停只有细环；勾选框 16px；已完成不画删除线、卡片去影；「新建分组」「新建项目」改成幽灵按钮；空泳道显示一句提示（如「没有过期的待办」）。
