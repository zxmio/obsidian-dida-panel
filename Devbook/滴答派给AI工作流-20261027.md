# 滴答待办派给 AI：队列约定与领活循环

滴答清单任务面板插件（`plugins/dida-panel`）从 0.1.0 起支持「派给 AI」。思路是：待办不是给我做的，是给 AI 派的活。面板负责把活丢进队列并立刻拉起 MakerPilot，Claude Code 负责成批把队列里的活领走。

## 一、队列约定

- 队列就是一个滴答标签，默认 `派给AI`，可在插件设置「派给 AI · 队列标签」里改。
- 任何未完成任务只要带这个标签，就算在队列里。跨项目通用，不需要每个项目加列。
- 完成任务时按滴答的常规方式完成即可，队列自动出列。中途不想让 AI 做了，任务菜单里「移出 AI 队列」把标签摘掉。

## 二、面板侧（方案 1）

任务行悬停时有一个机器人图标，展开卡片和「更多」菜单里也有「派给 AI」。点一次做两件事：

1. 给任务打上队列标签。
2. 按设置里的指令模板拼好一段指令，打开 MakerPilot，新建一个会话，把指令填进输入框。正文和来源笔记的深链会改写成 `[[路径|显示名]]`，MakerPilot 能把它们当上下文读到。

指令不会自动发送，看一眼再回车。MakerPilot 没启用时指令会复制到剪贴板。

只想入队、不想立刻处理：菜单里「只进 AI 队列，不打开 MakerPilot」。

项目总览第一行是「AI 队列」，点进去按项目分组看所有排队的活。

## 三、Claude Code 侧（方案 3）

在 Claude 桌面应用或终端里的 Claude Code 中，用滴答 MCP 领活。两种启动方式：

- 手动一次：直接把下面的提示词发给 Claude Code。
- 循环领活：`/loop 30m` 后面接下面的提示词，每半小时扫一次队列。

提示词（按需改标签名和工作区路径）：

```
你是我的 AI 执行助理，按下面流程领活并执行，全程用 dida365 MCP 工具操作滴答清单。

1. 用 filter_tasks，filter 里 status 填 [0]、tag 填 ["派给AI"]，取出队列里的全部任务。没有任务就直接回复「队列为空」结束。
2. 对每一条任务：
   - 读 title、content、projectId、columnId、tags、dueDate。content 里「正文：」「来源：」后面的 Obsidian 深链，file 参数 URL 解码后就是 vault 相对路径，vault 根目录是 /Users/todaylab/Documents/Todaylab，先把这些笔记读一遍再动手。
   - 判断任务类型并执行：写稿类按 ~/.claude/skills/writing-guide 的风格写进「正文」指向的笔记（没有就按工作区约定在 03内容输出 下新建，并把深链回写到任务 content 的「正文：」行）；研究类把结论写成一篇笔记并回写深链；代码类在对应仓库里开分支完成并在任务 content 里追加一行「结果：」说明。
   - 复杂任务拆给子代理并行做，单个任务不要超过 20 分钟，超时就把已完成的部分写进笔记并在任务 content 末尾追加「进度：」说明。
3. 每做完一条：用 update_task 把标签里的「派给AI」换成「AI已做」（其它标签保留），不要自己把 status 改成 2；是否标记完成由我在面板里确认。
4. 全部处理完，用一段话汇报：做了几条、每条产出在哪篇笔记、哪些没做完及原因。

不要创建新项目，不要删除任务，不要动队列以外的任务。
```

说明：

- 用「AI已做」标签代替直接完成，是为了留一道人工确认。确认后在面板里勾掉即可。
- 领活循环和面板互不依赖：面板只负责入队和即时派单，循环只认标签。
- 想让某个项目的看板列也能派活，把任务拖到任意列再点派给 AI 即可，列不影响队列。

## 四、设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 队列标签 | 派给AI | 面板打标签与循环领活共用 |
| 派活时在 MakerPilot 新建会话 | 开 | 关掉则追加到当前会话输入框 |
| 指令模板 | 见插件默认 | 占位符 `{{title}} {{project}} {{column}} {{due}} {{priority}} {{tags}} {{notes}} {{links}}`，空值所在行自动收掉 |

## 五、已知边界

- MakerPilot 没有公开 API，面板调用的是它插件实例上现成的三个方法（激活视图、新建会话、追加输入）。MakerPilot 升级若改了这些方法名，派活会退化成「指令复制到剪贴板」。
- 不自动发送指令，刻意保留一次人工过目。
- 循环领活依赖 Claude Code 会话里已连接 dida365 MCP。
