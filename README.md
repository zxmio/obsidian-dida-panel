# 滴答清单任务面板

在 Obsidian 右侧栏里增删改查滴答清单待办。数据走滴答清单官方 MCP 服务（`https://mcp.dida365.com`），插件本身不另存一份任务。

## 功能

- 侧栏面板三个页签：今天（含已过期、已完成）、收件箱、项目；搜索是顶栏右上角的放大镜图标。常用项目可以在项目操作面板里「置顶到页签栏」，排在项目后面（一道短竖线隔开），点一下直接进入；页签多了可横向滑动，右键置顶页签可取消置顶，也可以「页签名称…」给它起个短名（只改页签上的字，滴答里的项目名不变），改过的可一键恢复原名。
- 项目以总览为入口：顶部是「今天 / 过期 / AI 队列」三张数字卡；收件箱置顶，其余按滴答分组列出，分组可折叠。项目名开头的 emoji 当图标，每行显示未完成数与过期数，悬停换成「新建待办」和「更多」，右键同样弹出项目操作面板（顶部是项目名、所属分组、待办与过期数，下面是打开、新建待办、在主窗格打开看板、网页版打开；在项目里打开时多出切换项目、刷新）。面板头部和 AI 队列头部的「更多」也都换成了同样样式的面板，不再用 Obsidian 原生菜单。再点一次「项目」页签回到总览。
- 项目详情、收件箱、今天都支持列表 / 看板两种显示方式（各自记住）。项目和收件箱的看板按滴答里的分组排布，卡片拖到别的分组即移组，没有分组的任务归在最前面的「未分组」；今天的看板分「已过期 / 今天 / 已完成」三栏，拖进「今天」改到今天，拖进「已完成」直接完成。项目的「更多」菜单里可在主窗格新开一个页签铺开看板。
- 铺满切换：面板顶栏「铺满」按钮（或命令「铺满 / 还原任务面板」）把面板从右侧栏挪到主编辑区并收起左右侧栏，当前页签、项目和看板模式跟着走；开在主编辑区时同一个按钮变成「收回侧栏」，挪回右侧栏并恢复铺满前左右侧栏的开合。
- 新建任务直接出现在列表里，不等重拉；后台对账时旧内容照常显示，拉回来没变化就不重画，所以加任务不会整页闪一下，输入框也保持焦点可以接着打。
- 快速添加框下面有日期、优先级、标签、项目、分组五个快捷按钮（分组只在目标项目有分组时出现，默认第一个分组，也可选「未分组」），点开是贴着按钮的小面板：日期面板有常用日期、月历和常用时刻；优先级可按 1 / 2 / 3 / 0 直接选；标签和项目可搜索，标签能多选、能当场新建。面板里上下键移动、回车选择、Esc 回到输入框；已设置的按钮悬停露出清除。也能直接打速记 `明天 14:00 !高 #公众号 ^项目名`，按钮会实时显示识别结果。
- 新建 / 编辑弹窗：标题、项目与分组（新建时可选「未分组」）、日期、优先级、标签、备注。日期按钮打开的面板和快速添加的日期按钮是同一个：常用日期、月历、常用时刻，选完直接写回。备注框右下角可一键插入当前笔记的 Obsidian 深链（按钮上写着笔记名），格式与工作区约定一致；新建时不再自动附上。
- 任务操作：任务行的「更多」打开操作面板——顶部是派给 AI、编辑、打开关联笔记（没有关联笔记时是「建笔记」）、网页版几个常用动作；中间日期（今天 / 明天 / 下周一 / 其他… / 清除，「其他…」在操作面板旁边再开一层带月历和时刻的日期面板，操作面板不关）、重复（每天 / 工作日 / 每周 X / 每月 X 日 / 每年，已设的再点一下取消）和优先级（高 / 中 / 低 / 无）各一排，点一下生效；下面是分组列表（当前分组打勾）、移到其他项目，最底下是删除（点了直接删，不再弹确认）。列表行可以上下键加回车选。今天、收件箱、项目、AI 队列、看板卡片和搜索结果上右键，打开的也是这个面板。
- 项目：总览底部和顶部「更多」里有「新建项目」，可填名称、文件夹、视图（列表 / 看板）、颜色，建好直接进入。项目操作面板里「编辑项目…」改这几项，「归档项目…」把项目关闭（滴答开放的 MCP 接口没有删除项目，归档后可在滴答的「已关闭的清单」里找回，彻底删除需到滴答里操作）。编辑项目时可以换文件夹，也可以选「不放文件夹」移出来。总览里每个文件夹标题悬停露出「···」（或右键）：在这里新建项目、重命名、删除文件夹（只删文件夹，里面的项目留着、变成未分组）；总览底部「新建文件夹」。空文件夹也会列出来。收件箱不能改名或归档。
- 任务行右上角悬停只露出「⋯」（右键同样打开操作面板）。展开后依次是正文、检查项、子任务、「添加子任务」框，最底下一排常用图标：派给 AI（右键换去处）、打开笔记 / 创建笔记（没绑定笔记时是创建）、设置日期和时间、编辑。
- 清单型任务（滴答里带检查项的任务）：正文取滴答的描述，渲染成 Markdown，链接可点；卡片上显示检查项进度（如 1/5），展开后列出全部检查项，勾一下就同步回滴答。编辑弹窗里改这类任务的正文，写回的也是描述；弹窗正文下面是检查项编辑区：勾选、改字、悬停点叉删除，最后一行输入回车追加，在某一项里回车在它后面插一行、空行按退格删掉，保存时整组写回。
- 编辑弹窗的正文默认显示渲染后的样子，点正文空白处切到原文编辑，失焦回到预览。正文下面一排工具，对应正文里三种笔记链接：
  - 「来源」：这条待办是从哪篇笔记里来的（会议纪要、复盘）。只记一篇，写在末尾「来源：」一行，再选就替换（按钮变成「换来源」）。
  - 「关联笔记」：其它参考笔记，末尾追加「关联：」一行，可以加很多篇，同一篇不重复加。
  - 「创建笔记」：建一篇这条待办自己的笔记并和它绑定——笔记属性 `dida` 记下待办在滴答的地址，待办正文第一行写成「正文：[笔记](…)」。已有的待办当场写回滴答，不用等保存；新待办在保存成功后把地址补进笔记属性。绑定后按钮变成「打开笔记」。
  挑笔记时当前打开的那篇排第一。卡片上的笔记按钮、操作面板的「笔记」打开的都是「正文：」绑定的那篇；没绑定的老数据退回正文里第一条笔记链接。
- 正文的 Markdown：卡片展开和编辑弹窗预览用同一套渲染。指向本 vault 的笔记链接显示成笔记名、点了在 Obsidian 里打开（⌘ / Ctrl 点开新页签）；标题、列表、引用、代码、表格按面板字号收拢；正文里的任务列表（`- [ ]`）勾选框能点，卡片里点了直接存回滴答，弹窗里点了改在正文上、保存时一起写回。
- 建笔记：任务操作面板的「建笔记」（没绑定笔记时出现），或编辑弹窗的「创建笔记」。笔记放在来源笔记所在的文件夹（通常就是项目目录），没有来源就放在 Obsidian 设置的新笔记位置；文件名用待办标题，重名自动加序号；属性 `dida` 是回到滴答这条待办的地址，下面抄上待办正文和检查项。
- 时间段：滴答里带开始和结束的任务（16:00–17:00、跨几天的全天任务），卡片上显示成 16:00–17:00；在插件里改日期（操作面板、日期面板、编辑弹窗、拖进「今天」、任务体检）都会保留原来的时长，只选日子时原来的时刻也留着。
- 重复：卡片上的小循环图标表示重复任务，悬停看规则（每周一、每 2 周一三、每月 5 日……）。操作面板和编辑弹窗都能设：每天、每个工作日、每周 X、每月 X 日、每年，按任务的日子算；没日子的任务设重复时日子顺便定在今天。滴答里设的复杂规则照样显示，插件里改成常用档或取消。
- 批量操作：顶部「更多」里的「多选」，或 ⌘ / Ctrl 点任意一条任务进入多选。多选时点任务就是选中，底部出操作栏：全选、完成、改日期（只选日子就只换日子，各自的时刻和时长留着）、优先级、移到项目、删除；Esc 或「退出」结束。改日期和优先级一次提交给滴答。
- 标签管理：顶部「更多」里的「管理标签…」或命令「管理标签」。列出全部标签，可以改名、删除，两者都会同步到所有带这个标签的任务；删除点一下先变成「确认删除」，3 秒内再点一次才删。
- 子任务：展开一条任务，在「添加子任务」框里输入回车即建，可以连续添加；任务操作面板里的「子任务」按钮也能直达。子任务就是普通任务，排在父任务正下方，完成、编辑、删除、右键操作都一样；父任务行上显示完成进度（如 2/5），只数还存在的子任务：滴答删掉子任务后父任务里还留着它的记录，插件会在后台核对一次，删掉的不算。任务操作面板里还能「设为子任务…」（同样在旁边再开一层，搜索同项目的任务挂上去）和「转成独立任务」。看板里子任务收进父任务卡片：展开父任务（或点进度）就列出全部子任务，每一行都能勾选完成、展开、编辑、右键和派给 AI，和普通任务一样。
- 分组：项目详情底部（看板里是最后一条泳道）有「新建分组」，输入名字回车即建，排在最后。分组标题和泳道右上角的「···」（或右键）打开分组操作：重命名、在左侧 / 右侧（列表里是上方 / 下方）添加分组、左移 / 右移、删除。删除分组时滴答开放的 MCP 接口没有对应工具，插件会说明原因并在网页版打开这个项目，到那里删。看板每条泳道底部是「添加到 XX」行，点进去输入回车即建在这个分组，支持速记，标题旁的「+」也能直达；泳道里的卡片全部列出，不折叠。
- 派给 AI：会给任务打上队列标签（默认「派给AI」），再把拼好的指令（正文与来源笔记改写成 `[[路径|显示名]]`）送到四个去处之一：MakerPilot（新建会话，填进输入框）、Claude Code（Claude 桌面 App 新开会话，工作目录默认是本 vault）、Claude 对话（Claude 桌面 App 新开对话）、Codex（ChatGPT 桌面 App 新开线程，工作目录同上）。都只填好指令不自动发送；App 没装或打不开时指令复制到剪贴板。设置里选默认去处和工作目录；任务行的机器人图标派给默认去处，右键它或任务菜单的「派给 AI…」会弹出选择面板：四个去处带各自的 logo，按 1 到 4 直选，悬停可「设为默认」，没装的 App 灰掉并标「未安装」，底部是只进队列 / 移出队列。项目总览第一行是「AI 队列」。Claude Code 侧的领活循环提示词见 `Devbook/滴答派给AI工作流-20261027.md`。
- 底部 AI 对话框（布局照 MakerPilot：标题栏、右对齐的提问气泡、可折叠的执行步骤卡片、圆角输入框与 AI 所见范围）：展开即进入对话模式，铺满整个面板，收起回到清单；输入框会自动让开 Obsidian 底部的状态栏。一句话让 AI 增删改查滴答（「把今天过期的都推到明天」「在内容创作的选题池加一条…」）。通道是本机 Claude Code（Claude Agent SDK，用你已有的登录态，不配密钥），滴答工具用插件自己的登录令牌直挂 MCP。查询与单条新建 / 更新 / 完成自动放行；删除、批量、跨项目移动弹确认框；文件与命令类工具禁用；不加载 `~/.claude` 的全局设置。方案见 `Devbook/滴答面板AI对话框方案-20261027.md`。
- 任务体检：表头听诊器图标或命令「任务体检」。选范围（全部待办 / 收件箱 / 当前项目），Claude 一次读完任务清单，挑出描述不清、分类不当、长期搁置、过期未处理、疑似重复五类问题，每条给 1 到 3 个处理选项（改标题、移项目或列、改日期、完成、删除、派给 AI 等），点一下由插件直接执行，删除也一样不弹确认。体检调用不给 AI 任何工具，只读、只出建议。
- 编辑器右键：选中文本后「创建为滴答待办」「创建并排到今天」「关联到已有待办」。
- 笔记内嵌任务块：

  ````markdown
  ```dida
  project: 内容创作
  column: 写作中
  ```
  ````

- 命令面板：打开任务面板、铺满 / 还原任务面板、管理标签、打开项目总览、在主窗格打开项目看板、快速添加待办、从选中文本创建待办、把当前笔记关联到已有待办、在光标处插入任务块、切换到项目、任务体检、立即同步、登录滴答清单。

## 设计规范

界面数值（颜色、字号、圆角、控件高度、阴影）只在 `styles.css` 顶部的变量块里定义，组件只引用变量，深色模式只覆写颜色。视觉以自己的设计稿为准：暖白页面底、白卡片配柔和投影、圆形勾选框（高优先级红圈、中优先级深灰圈）、胶囊标签、无底色的泳道。规范见 `Devbook/滴答面板设计规范-20261028.md`；`tests/styles.test.mjs` 会拦住变量块以外写死的颜色、圆角和字号。

## 登录

设置页点「登录滴答清单」，插件会向 MCP 服务动态注册一个客户端，用系统浏览器完成授权（PKCE），回调落在本机 `127.0.0.1` 的临时端口。令牌只保存在本库 `.obsidian/plugins/todaylab-dida-panel/data.json` 里。

也可以直接粘贴一个 Bearer 访问令牌，优先级高于浏览器登录。

## 开发

```bash
npm install
npm run build
npm test
```

安装到 vault：

```bash
mkdir -p /path/to/vault/.obsidian/plugins/todaylab-dida-panel
cp plugins/dida-panel/{manifest.json,main.js,styles.css} /path/to/vault/.obsidian/plugins/todaylab-dida-panel/
```

## 依赖

- `@anthropic-ai/claude-agent-sdk` 0.3.293（与 MakerPilot 同版本）：官方 SDK，拉起本机 Claude Code 并带 MCP 工具。打包时需要三个补丁（`import.meta.url` 改 `__filename`、剔除未用的 zod / MCP peer、timer 的 `unref()` 改可选调用），见 `esbuild.config.mjs`。

## 已知限制

- 桌面端专用：浏览器登录依赖本机回环端口。
- MCP 响应用 Obsidian 的 `requestUrl` 一次性读取，不支持长连接推送；滴答的工具调用都是一问一答，够用。
- 滴答授权服务器目前不发 refresh_token，令牌过期后需要重新点一次登录。
- 看板拖拽只在列之间移动，不改列内顺序；循环任务编辑、子任务层级编辑留到下一版。
