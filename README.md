# 滴答清单任务面板

在 Obsidian 右侧栏里增删改查滴答清单待办。数据走滴答清单官方 MCP 服务（`https://mcp.dida365.com`），插件本身不另存一份任务。

## 功能

- 侧栏面板四个视图：今天（含已过期、已完成）、收件箱、项目、搜索。
- 项目以总览为入口：顶部是「今天 / 过期 / AI 队列」三张数字卡；收件箱置顶，其余按滴答分组列出，分组可折叠。项目名开头的 emoji 当图标，每行显示未完成数与过期数，悬停换成「新建待办」和「更多」，右键同样弹出菜单（打开、新建、在主窗格打开看板、网页版打开）。再点一次「项目」页签回到总览。
- 项目详情、收件箱、今天都支持列表 / 看板两种显示方式（各自记住）。项目和收件箱的看板按滴答里的分组排布，卡片拖到别的分组即移组，没有分组的任务归在最前面的「未分组」；今天的看板分「已过期 / 今天 / 已完成」三栏，拖进「今天」改到今天，拖进「已完成」直接完成。项目的「更多」菜单里可在主窗格新开一个页签铺开看板。
- 快速添加框下面有日期、优先级、标签、项目、分组五个快捷按钮（分组只在目标项目有分组时出现，默认第一个分组，也可选「未分组」），点开是贴着按钮的小面板：日期面板有常用日期、月历和常用时刻；优先级可按 1 / 2 / 3 / 0 直接选；标签和项目可搜索，标签能多选、能当场新建。面板里上下键移动、回车选择、Esc 回到输入框；已设置的按钮悬停露出清除。也能直接打速记 `明天 14:00 !高 #公众号 ^项目名`，按钮会实时显示识别结果。
- 新建 / 编辑弹窗：标题、项目与分组（新建时可选「未分组」）、日期、优先级、标签、备注。备注框右下角可一键插入当前笔记的 Obsidian 深链（按钮上写着笔记名），格式与工作区约定一致；新建时不再自动附上。
- 任务操作：完成、编辑、改日期、改优先级、移列、移项目、删除（删除前确认）、在滴答中打开、打开关联笔记。
- 派给 AI：任务行悬停的机器人图标、展开卡片和菜单里的「派给 AI」，会给任务打上队列标签（默认「派给AI」），并打开 MakerPilot 新建会话、把拼好的指令填进输入框（正文与来源笔记改写成 `[[路径|显示名]]`）。项目总览第一行是「AI 队列」。Claude Code 侧的领活循环提示词见 `Devbook/滴答派给AI工作流-20261027.md`。
- 底部 AI 对话框（布局照 MakerPilot：标题栏、右对齐的提问气泡、可折叠的执行步骤卡片、圆角输入框与 AI 所见范围）：展开即进入对话模式，铺满整个面板，收起回到清单；输入框会自动让开 Obsidian 底部的状态栏。一句话让 AI 增删改查滴答（「把今天过期的都推到明天」「在内容创作的选题池加一条…」）。通道是本机 Claude Code（Claude Agent SDK，用你已有的登录态，不配密钥），滴答工具用插件自己的登录令牌直挂 MCP。查询与单条新建 / 更新 / 完成自动放行；删除、批量、跨项目移动弹确认框；文件与命令类工具禁用；不加载 `~/.claude` 的全局设置。方案见 `Devbook/滴答面板AI对话框方案-20261027.md`。
- 任务体检：表头听诊器图标或命令「任务体检」。选范围（全部待办 / 收件箱 / 当前项目），Claude 一次读完任务清单，挑出描述不清、分类不当、长期搁置、过期未处理、疑似重复五类问题，每条给 1 到 3 个处理选项（改标题、移项目或列、改日期、完成、删除、派给 AI 等），点一下由插件直接执行，删除仍需确认。体检调用不给 AI 任何工具，只读、只出建议。
- 编辑器右键：选中文本后「创建为滴答待办」「创建并排到今天」「关联到已有待办」。
- 笔记内嵌任务块：

  ````markdown
  ```dida
  project: 内容创作
  column: 写作中
  ```
  ````

- 命令面板：打开任务面板、打开项目总览、在主窗格打开项目看板、快速添加待办、从选中文本创建待办、把当前笔记关联到已有待办、在光标处插入任务块、切换到项目、任务体检、立即同步、登录滴答清单。

## 登录

设置页点「登录滴答清单」，插件会向 MCP 服务动态注册一个客户端，用系统浏览器完成授权（PKCE），回调落在本机 `127.0.0.1` 的临时端口。令牌只保存在本库 `.obsidian/plugins/todaylab-dida-panel/data.json` 里。

也可以直接粘贴一个 Bearer 访问令牌，优先级高于浏览器登录。

## 开发

```bash
npm install
npm run build
npm test
```

安装到 vault：

```bash
mkdir -p /path/to/vault/.obsidian/plugins/todaylab-dida-panel
cp plugins/dida-panel/{manifest.json,main.js,styles.css} /path/to/vault/.obsidian/plugins/todaylab-dida-panel/
```

## 依赖

- `@anthropic-ai/claude-agent-sdk` 0.3.293（与 MakerPilot 同版本）：官方 SDK，拉起本机 Claude Code 并带 MCP 工具。打包时需要三个补丁（`import.meta.url` 改 `__filename`、剔除未用的 zod / MCP peer、timer 的 `unref()` 改可选调用），见 `esbuild.config.mjs`。

## 已知限制

- 桌面端专用：浏览器登录依赖本机回环端口。
- MCP 响应用 Obsidian 的 `requestUrl` 一次性读取，不支持长连接推送；滴答的工具调用都是一问一答，够用。
- 滴答授权服务器目前不发 refresh_token，令牌过期后需要重新点一次登录。
- 看板拖拽只在列之间移动，不改列内顺序；循环任务编辑、子任务层级编辑留到下一版。
